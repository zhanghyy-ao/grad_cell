# 基于 Chen2020 固定材料体系的电芯结构逆向设计完整流程

## 1. 文档目的

本文档给出 GradCell 项目中“固定材料参数、优化电芯结构”的完整科研与工程流程，覆盖：

- Chen2020 参数集在项目中的作用和使用边界；
- 电芯结构设计变量、固定参数和约束条件；
- 随机设计生成、SPMe/DFN 仿真及数据记录方式；
- 性能代理模型和可行性模型的训练方法；
- 根据目标性能进行电芯结构逆向设计的方法；
- SPMe 大规模搜索与 DFN 高精度复核的分工；
- 当前实验已经证明的内容、尚未证明的内容；
- 当前代码需要修改的问题及推荐实施顺序；
- 每个阶段的通过标准和实验记录要求。

本文档中的仿真结果属于基于 Chen2020 和电化学模型得到的模型预测，不等同于真实电芯测量结果，也不能直接作为新材料发现的证据。

---

## 2. 研究问题定义

本项目第一阶段研究的问题是：

> 在正极、负极、电解液等材料体系固定的情况下，改变电极厚度、孔隙率、活性材料比例和 N/P 比等电芯结构参数，寻找满足能量、功率、电压、质量和制造约束的电芯设计。

整体计算链为：

```text
Chen2020 固定材料参数
        ↓
可制造的电芯结构设计空间
        ↓
随机生成合法结构
        ↓
SPMe 大规模仿真并生成标签
        ↓
训练性能代理模型和可行性模型
        ↓
根据目标性能进行梯度逆向搜索
        ↓
真实 SPMe 回代验证
        ↓
DFN 高精度复核
        ↓
补充困难样本并迭代训练
```

这里不能直接随机生成“电芯性能”。正确的数据产生关系是：

```text
随机生成结构参数 → 物理仿真 → 得到性能标签
```

如果结构和性能都独立随机生成，两者之间没有物理对应关系，神经网络无法学习真实规律。

## 3. Chen2020 在流程中的作用

PyBaMM 中可以通过以下方式加载 Chen2020：

```python
parameter_values = pybamm.ParameterValues("Chen2020")
```

Chen2020 提供一套已经参数化的锂离子电芯基准，包括正负极、电解液、几何、热学和工作条件等参数。项目将其作为固定材料体系和标称电芯基准，而不是将其视为完整的真实实验数据集。

### 3.1 第一阶段应固定的材料参数

建议固定以下参数：

- 正极和负极开路电压函数；
- 正极和负极最大锂浓度；
- 正极和负极颗粒半径；
- 正极和负极固相扩散系数；
- 正极和负极界面反应速率常数；
- 电解液扩散系数；
- 电解液电导率；
- 阳离子迁移数；
- 热力学因子；
- 材料密度、比热和热导率；
- 基准温度及相应温度依赖函数。

### 3.2 不应作为第一阶段设计变量的参数

如果研究目标是“固定材料体系下的结构优化”，以下参数不应由网络改变：

- 正极颗粒扩散率倍率；
- 负极颗粒扩散率倍率；
- 反应动力学倍率；
- 电解液电导率倍率；
- 材料最大浓度；
- 开路电压曲线。

当前代码中的以下两个变量属于材料输运参数：

```text
Positive particle diffusivity multiplier
Negative particle diffusivity multiplier
```

纯结构实验中应固定为 `1.0`，或者从神经网络输出维度中删除。后续可以增加“结构与材料输运参数联合优化”实验，但应与固定材料主实验分开报告。

## 4. 电芯结构设计空间

### 4.1 第一版推荐设计变量

第一版建议使用六个核心变量：

\[
x=[L_p,L_n,\varepsilon_p,\varepsilon_n,\phi_p,N/P]
\]

其中：

| 变量 | 含义 | 单位 |
|---|---|---|
| \(L_p\) | 正极厚度 | m |
| \(L_n\) | 负极厚度 | m |
| \(\varepsilon_p\) | 正极孔隙率 | 无量纲 |
| \(\varepsilon_n\) | 负极孔隙率 | 无量纲 |
| \(\phi_p\) | 正极活性材料体积分数 | 无量纲 |
| \(N/P\) | 负极容量与正极容量比 | 无量纲 |

负极活性材料体积分数 \(\phi_n\) 可以通过容量平衡推导，避免变量冗余。

### 4.2 后续可以加入的变量

- 隔膜厚度；
- 隔膜孔隙率；
- 电极面积；
- 正负极集流体厚度；
- 电极堆叠层数；
- 电解液填充量；
- 壳体和极耳等工程结构参数。

第一阶段不建议一次加入全部变量。应先完成六维结构空间的稳定闭环，再逐步扩大。

### 4.3 初始建议范围

以下范围只适合作为第一轮保守范围，最终需要结合 Chen2020 标称参数、制造文献、解码器可行性和倍率扫描结果校准。

| 参数 | 第一轮示例范围 |
|---|---:|
| 正极厚度 | 60–100 μm |
| 负极厚度 | 70–110 μm |
| 正极孔隙率 | 0.20–0.40 |
| 负极孔隙率 | 0.20–0.40 |
| 正极活性材料体积分数 | 0.50–0.72 |
| N/P | 1.05–1.25 |
| 隔膜孔隙率（后续） | 0.35–0.55 |
| 隔膜厚度（后续） | 10–25 μm |

## 5. 结构约束与可行解码器

神经网络或随机采样器首先产生无约束潜变量：

\[
z\in\mathbb{R}^d
\]

解码器将其映射为合法结构：

\[
x=D(z)
\]

对于具有上下限的变量，可以使用：

\[
x=x_{\min}+(x_{\max}-x_{\min})\operatorname{sigmoid}(z)
\]

### 5.1 体积分数约束

每个电极区域应满足：

\[
\varepsilon+\phi_{\mathrm{active}}+\phi_{\mathrm{inactive}}=1
\]

并要求：

\[
\phi_{\mathrm{inactive}}\geq\phi_{\mathrm{inactive,min}}
\]

### 5.2 基本合法性约束

每个设计在调用 PyBaMM 前必须通过以下检查：

- 厚度为正且位于制造范围；
- 所有体积分数位于 0 和 1 之间；
- 活性材料、孔隙和非活性组分之和为 1；
- N/P 位于指定范围；
- 正负极容量均为正且有限；
- 质量为正且有限；
- 面容量不超过设定上限；
- 1C、3C 电流为正且有限；
- 初始化学计量比处于有效范围。

不满足约束的设计不应进入 PyBaMM，但必须保留结构及失败标签，例如：

```text
manufacturing_infeasible
capacity_balance_failed
invalid_volume_fraction
invalid_initial_state
```

## 6. 容量、N/P、质量和电流必须统一

同一个设计必须在容量计算、质量计算、SPMe、DFN 和 C-rate 电流定义中代表同一块电芯。

### 6.1 正极理论可用容量

\[
Q_p=
\frac{FAL_p\phi_pc_{s,p}^{\max}\Delta\theta_p}{3600}
\]

### 6.2 负极理论可用容量

\[
Q_n=
\frac{FAL_n\phi_nc_{s,n}^{\max}\Delta\theta_n}{3600}
\]

其中：

- \(F\) 为法拉第常数；
- \(A\) 为电极面积；
- \(L\) 为电极厚度；
- \(\phi\) 为活性材料体积分数；
- \(c_s^{\max}\) 为材料最大锂浓度；
- \(\Delta\theta\) 为可用化学计量窗口。

### 6.3 N/P 容量比

\[
N/P=\frac{Q_n}{Q_p}
\]

如果 N/P 是输入变量，可以通过容量平衡反推负极活性材料体积分数：

\[
\phi_n=
\frac{(N/P)Q_p3600}
{FAL_nc_{s,n}^{\max}\Delta\theta_n}
\]

之后必须再次检查：

\[
0<\phi_n<1-\varepsilon_n-\phi_{\mathrm{inactive},n}
\]

### 6.4 标称容量

可以先定义：

\[
Q_{\mathrm{nominal}}=\min(Q_p,Q_n)
\]

但必须通过 Chen2020 标称设计的实际放电仿真校准化学计量窗口，避免理论容量明显高估实际可用容量。

当前项目中的临时公式：

\[
Q=5\,\mathrm{Ah}\frac{\phi_p}{0.665}
\]

已经改善了原公式对容量尺度的明显高估，但它只随正极活性材料比例变化。加入面积和电极厚度后，至少应扩展为：

\[
Q=5\,\mathrm{Ah}
\frac{A}{A_0}
\frac{L_p}{L_{p,0}}
\frac{\phi_p}{\phi_{p,0}}
\]

最终建议使用正负极容量平衡公式，而不是长期依赖单变量缩放。

### 6.5 C-rate 对应电流

每个随机设计的容量不同，因此电流必须随设计变化：

\[
I_{1C}=Q_{\mathrm{nominal}}
\]

\[
I_{3C}=3Q_{\mathrm{nominal}}
\]

例如容量为 4.2 Ah 的设计：

```text
1C 电流 = 4.2 A
3C 电流 = 12.6 A
```

不能让所有设计都固定使用 Chen2020 标称电芯的 5 A 和 15 A。

### 6.6 质量计算

质量模型至少需要与以下变量一致：

- 电极面积；
- 正负极厚度；
- 活性材料比例；
- 非活性材料比例；
- 孔隙中的电解液；
- 隔膜；
- 集流体。

如果当前只计算电极堆质量，指标应称为 `stack-specific energy` 或“基于电极堆质量的比能量”，不能直接解释为完整商业电芯比能量。

## 7. 初始 SOC 和锂库存对齐

改变电极厚度、活性材料比例和 N/P 后，如果仍完全沿用 Chen2020 原始初始浓度，不同设计可能并不是从相同初始状态开始。

这可能造成：

- 不同设计的初始 SOC 不一致；
- 可循环锂库存与新容量不一致；
- 某些设计初始时已接近正负极化学计量边界；
- 3C 失败被错误归因于结构设计；
- 不同设计的性能比较不公平。

项目需要明确采用一种初始化规则，例如：

1. 所有设计保持相同初始 SOC；
2. 所有设计保持相同初始开路电压；
3. 根据新 N/P 和可循环锂库存重新求解正负极初始化学计量比。

推荐使用第三种方式，并在数据中记录：

```text
initial_soc
initial_stoichiometry_positive
initial_stoichiometry_negative
cyclable_lithium_inventory
initialization_status
```

## 8. 随机设计生成策略

### 8.1 潜变量高斯采样

可使用：

\[
z\sim\mathcal N(0,\sigma^2I)
\]

再通过硬可行解码器得到结构：

\[
x=D(z)
\]

优点是容易与当前可微设计网络连接，但大量样本可能集中在设计空间中心。

### 8.2 空间覆盖采样

为提高设计空间覆盖率，推荐同时使用：

- Sobol 序列；
- Latin Hypercube Sampling；
- 分层采样；
- 设计边界加密采样。

第一批数据建议由以下部分组成：

```text
60% Sobol 或 LHS 空间覆盖样本
20% Chen2020 标称结构附近扰动样本
10% 设计上下限附近样本
10% 已知困难、高性能或可行性边界样本
```

### 8.3 推荐数据规模

| 阶段 | SPMe 设计数量 | 目的 |
|---|---:|---|
| 调试 | 100–200 | 验证数据链路和记录系统 |
| 第一轮训练 | 2,000–5,000 | 训练初始代理和分类器 |
| 后续扩充 | 10,000–50,000 | 改善边界和高性能区域预测 |

DFN 配对数据建议先从 50–200 个设计开始，不建议直接生成数千个 DFN 样本。

## 9. SPMe 数据生成流程

SPMe 负责大规模快速数据生成。每个结构至少运行：

- 1C：评估常规放电能力和比能量；
- 3C：评估高倍率能力和比功率。

更完整的倍率扫描可以使用：

```text
0.5C → 1C → 1.5C → 2C → 2.5C → 3C
```

### 9.1 单个样本的处理流程

```text
生成潜变量
    ↓
解码为结构参数
    ↓
检查制造和容量约束
    ↓
计算容量、质量和 C-rate 电流
    ↓
对齐初始 SOC 和化学计量状态
    ↓
运行 SPMe 1C
    ↓
运行 SPMe 3C
    ↓
检查求解状态、结束时间和有限性
    ↓
计算有效性能标签
    ↓
保存结构、曲线、指标和失败原因
```

### 9.2 成功判据

一次仿真只有同时满足以下条件，才应视为成功：

```text
求解过程未抛出异常
完成请求的时间范围或满足预定义的有效终止规则
电压和关键状态变量全部有限
需要梯度时 Jacobian 全部有限
没有违反物理和制造约束
```

不能仅以“求解器没有抛异常”作为成功标准。

### 9.3 电压截止模式

应区分训练模式和标签/验证模式。

#### 标签和最终验证模式

使用真实工程截止电压，例如 2.5 V。提前触发最低电压时记录：

```text
completed_requested_horizon = false
termination = event: Minimum voltage [V]
failure_type = undervoltage
```

#### 可微训练模式

为了保持固定长度时间网格，可以暂时将硬截止事件移开，并使用平滑电压惩罚。但低于工程截止电压之后的能量不能计入真实性能标签。

## 10. 性能标签计算

### 10.1 放电容量

\[
Q_{\mathrm{discharge}}=
\int_0^{t_{\mathrm{end}}}\frac{|I(t)|}{3600}\,dt
\]

### 10.2 放电能量

\[
E=
\int_0^{t_{\mathrm{end}}}
\frac{V(t)|I(t)|}{3600}\,dt
\]

### 10.3 平均功率

\[
P_{\mathrm{avg}}=\frac{E}{t_{\mathrm{end}}/3600}
\]

### 10.4 比能量

\[
E_{\mathrm{specific}}=\frac{E}{m}
\]

### 10.5 比功率

\[
P_{\mathrm{specific}}=\frac{P_{\mathrm{avg}}}{m}
\]

### 10.6 推荐保存的标签

- 1C 放电容量；
- 1C 总能量；
- 1C 比能量；
- 1C 平均电压；
- 1C 最低电压；
- 3C 放电容量；
- 3C 总能量；
- 3C 比功率；
- 3C 平均电压；
- 3C 最低电压；
- 实际结束时间；
- 是否完成目标工况；
- 最大可行倍率；
- 求解器和物理可行性标签。

任何无效仿真都不能通过简单填零获得回归标签。失败样本只用于可行性分类或失败机制分析。


### 11.3 曲线文件

电压、时间和内部状态曲线建议保存为 NPZ、HDF5 或 Zarr，而不是全部写入 CSV：

```text
design_id
time_1c[151]
voltage_1c[151]
time_3c[151]
voltage_3c[151]
```

### 11.4 失败类型

推荐统一使用：

```text
valid
manufacturing_infeasible
capacity_balance_failed
invalid_initial_state
undervoltage
early_termination
nonfinite_trajectory
nonfinite_jacobian
solver_convergence_failure
solver_error_failure
solver_failure_unknown
```

求解器失败不能未经复核就全部解释成物理不可行。

## 12. 数据集划分

建议按照 `design_id` 划分：

```text
训练集：70%
验证集：15%
测试集：15%
```

同一个设计的不同倍率记录必须属于同一个子集，避免数据泄漏。

建议额外建立：

- 插值测试集：位于训练设计范围内部；
- 边界测试集：接近参数上下限；
- 高倍率测试集：2.5C–3C；
- DFN 测试集：完全未参与代理训练的设计；
- 标称附近测试集：评估 Chen2020 基准附近精度。

后续如引入真实电芯数据，应按电芯或生产批次划分，而不是把同一电芯的不同循环随机拆分。

## 13. 需要训练的模型

不建议只训练一个模型。第一阶段至少需要两个模型，后续增加 DFN 修正模型。

### 13.1 模型 A：SPMe 可行性分类器

输入：

\[
x=[L_p,L_n,\varepsilon_p,\varepsilon_n,\phi_p,\phi_n,N/P]
\]

输出：

\[
p_{\mathrm{SPMe-valid}}
\]

标签建议定义为：

```text
1：1C 和 3C 均满足有效性要求
0：制造失败、欠压、提前终止、NaN 或求解失败
```

基本损失函数：

\[
\mathcal L_{\mathrm{cls}}=
\operatorname{BCEWithLogitsLoss}
\]

应根据正负样本比例设置类别权重，并重点关注把不可行设计错误判断为可行设计的比例。

### 13.2 模型 B：SPMe 性能代理模型

只使用具有有效性能标签的样本训练。

输入：

\[
x
\]

输出示例：

\[
y=[E_{1C},P_{3C},V_{\min,1C},V_{\min,3C},Q]
\]

基础多任务损失：

\[
\mathcal L_{\mathrm{reg}}=
\sum_j w_j\operatorname{MSE}(\hat y_j,y_j)
\]

输入和输出必须分别标准化：

\[
x'=\frac{x-\mu_x}{\sigma_x}
\]

\[
y'=\frac{y-\mu_y}{\sigma_y}
\]

训练后必须与模型权重一起保存 \(\mu_x,\sigma_x,\mu_y,\sigma_y\)。

### 13.3 模型 C：DFN 可行性与多保真修正模型

使用少量同设计的 SPMe/DFN 配对数据。

DFN 可行性模型：

\[
x\rightarrow p_{\mathrm{DFN-valid}}
\]

SPMe 到 DFN 的修正模型：

\[
[x,y_{\mathrm{SPMe}}]
\rightarrow
\Delta y=y_{\mathrm{DFN}}-y_{\mathrm{SPMe}}
\]

最终高精度预测：

\[
\hat y_{\mathrm{DFN}}=
y_{\mathrm{SPMe}}+\Delta\hat y
\]

## 14. 性能代理模型训练流程

### 14.1 基础网络结构

对于 6–10 维输入，普通 MLP 已经足够作为基线：

```text
输入层：6–10
隐藏层 1：128，SiLU
隐藏层 2：256，SiLU
隐藏层 3：256，SiLU
隐藏层 4：128，SiLU
输出层：5
```

可以加入 LayerNorm、残差连接和少量 Dropout，但首先应保证数据和标签正确。

### 14.2 基础训练配置

```text
优化器：AdamW
初始学习率：1e-3
batch size：64–256
学习率调度：ReduceLROnPlateau 或余弦退火
早停：根据验证集损失
随机种子：固定并记录
```

### 14.3 每轮训练过程

```text
读取训练 batch
    ↓
输入和标签标准化
    ↓
模型正向预测
    ↓
计算多任务损失
    ↓
反向传播
    ↓
更新模型参数
    ↓
周期性计算验证集指标
    ↓
保存最佳模型和标准化参数
```

### 14.4 必须保存的训练记录

- epoch 或 step；
- 训练损失；
- 验证损失；
- 每个目标的 MAE/RMSE；
- 当前学习率；
- 最佳模型所在 step；
- early stopping 状态；
- 模型参数；
- 数据集版本和划分 ID；
- Git commit；
- Python、PyTorch、PyBaMM 版本；
- 随机种子。

### 14.5 评估指标

回归模型对每个输出分别报告：

- MAE；
- RMSE；
- 相对误差；
- \(R^2\)；
- 最大误差；
- 95% 分位误差。

分类模型报告：

- accuracy；
- precision；
- recall；
- F1；
- ROC-AUC；
- 混淆矩阵；
- 不可行样本被错误预测为可行的比例。

## 15. 逆向设计方法

普通的“目标性能直接映射到唯一结构”存在一对多问题。同一个目标性能可能由多种结构实现，直接使用 MSE 训练 `性能 → 结构` 模型可能得到多个可行结构的平均值。

第一阶段推荐直接优化潜变量。

### 15.1 梯度优化链

```text
潜变量 z
   ↓
硬可行解码器 D(z)
   ↓
结构 x
   ↓
性能代理模型和可行性模型
   ↓
预测能量、功率、电压和可行概率
   ↓
目标函数
   ↓
对 z 反向传播并更新
```

### 15.2 示例目标函数

如果目标是提高 1C 比能量和 3C 比功率，同时保证 3C 最低电压和可行概率：

\[
\mathcal L=
-w_E\hat E_{1C}
-w_P\hat P_{3C}
+\lambda_V\operatorname{ReLU}(2.5-\hat V_{\min,3C})^2
+\lambda_F\operatorname{ReLU}(0.95-p_{\mathrm{valid}})^2
\]

还可以加入质量、面容量和制造边界惩罚。

### 15.3 多起点优化

每个目标建议同时初始化 100–1000 个潜变量，避免只得到单一局部最优解。

最终保留：

- 能量最高候选；
- 功率最高候选；
- 综合目标候选；
- 能量—功率 Pareto 前沿；
- 不同质量约束下的候选；
- 结构彼此有明显差异的候选。

### 15.4 对比基线

逆向设计至少应与以下方法在相同计算预算下比较：

- 随机搜索；
- Sobol 搜索；
- 贝叶斯优化；
- 遗传算法或 NSGA-II；
- Chen2020 标称结构。

只有当梯度方法更快或能够找到更优的可验证设计时，才能说明逆向设计方法具有优势。

## 16. SPMe 真实回代验证

代理模型产生的候选不能直接作为最终结果。每个候选必须重新运行真实 SPMe：

```text
代理模型产生候选
        ↓
真实 SPMe 仿真
        ↓
比较代理预测和物理结果
```

对每个指标计算：

\[
e_{\mathrm{surrogate}}=
|y_{\mathrm{SPMe}}-\hat y_{\mathrm{surrogate}}|
\]

如果最优候选的代理误差很大，说明优化器进入了代理模型不可靠的区域。处理方式为：

1. 将候选加入 SPMe 数据集；
2. 在候选附近补充采样；
3. 重新训练代理模型；
4. 再次执行逆向设计。

## 17. DFN 高精度复核

DFN 的职责是：

- 生成少量高精度标签；
- 判断高倍率物理可行性；
- 识别 SPMe 忽略的电解液和颗粒内部梯度；
- 校正 SPMe 性能偏差；
- 验证最终候选。

不建议让 DFN 直接参与数千次神经网络训练迭代。

### 17.1 DFN 样本选择

第一轮可以选择：

```text
20 个随机设计
20 个 SPMe 可行性边界设计
20 个 SPMe 高性能候选
Chen2020 标称设计
```

### 17.2 倍率扫描

```text
0.5C → 1C → 1.5C → 2C → 2.5C → 3C
```

逐渐升高倍率可以找到最大可行倍率和首次失败点，而不是只知道 3C 成功或失败。

### 17.3 DFN 推荐记录

- 完整电压曲线；
- 实际结束时间；
- 最大可行倍率；
- 最低电压；
- 电解液最低浓度；
- 正负极颗粒表面浓度；
- 固相和电解液电势；
- 反应过电势；
- 局部反应电流密度；
- 求解器状态和错误类型；
- SPMe 与 DFN 的性能差异。

### 17.4 最终通过标准

候选至少应满足：

```text
DFN 无求解异常
完成目标工况或按物理截止规则正常结束
电压和关键内部状态全部有限
不发生不允许的欠压
关键浓度不越过物理边界
结构满足制造约束
性能优于 Chen2020 标称设计或指定基线
```

## 18. 主动学习闭环

完整系统不是一次训练结束，而是循环改进：

```text
SPMe 生成初始数据
        ↓
训练性能和可行性代理
        ↓
执行逆向搜索
        ↓
SPMe/DFN 验证候选
        ↓
发现误差大、失败或高不确定性区域
        ↓
在这些区域补充样本
        ↓
重新训练并再次搜索
```

优先补充以下样本：

- 代理模型预测不确定性最高的设计；
- 接近 3C 可行性边界的设计；
- SPMe 与 DFN 差异最大的设计；
- 梯度搜索反复到达的高性能区域；
- 求解器失败但物理原因不明确的设计。

## 19. SPMe 与 DFN 的职责分工

| 任务 | SPMe | DFN |
|---|---|---|
| 大规模随机数据生成 | 主要负责 | 少量样本 |
| 神经网络监督训练 | 主要负责 | 不直接参与大量迭代 |
| 梯度逆向搜索 | 主要负责 | 通常不直接参与 |
| 初步可行性判断 | 负责 | 复核 |
| 3C 高倍率最终判断 | 参考 | 主要负责 |
| 内部浓度与极化分析 | 简化 | 高精度 |
| 最终性能报告 | 初步 | 最终模型验证 |
| 计算成本 | 较低 | 较高 |

推荐架构为：

> SPMe 负责大规模训练和搜索；DFN 负责高精度标签、可行性判断、多保真校正和最终复核。

## 20. 当前实验结果说明了什么

### 20.1 Toy 端到端梯度验证

此前结果约为：

```text
median relative error ≈ 2.14e-10
max relative error ≈ 3.05e-9
```

说明：

- 可行解码器的梯度链基本正确；
- 指标和目标函数能够传播梯度；
- PyTorch 自动微分与有限差分高度一致。

这只证明数学和软件链条正确，不证明真实 DFN 在整个设计空间稳定。

### 20.2 PyBaMM 标称物理梯度验证

此前结果约为：

```text
autodiff ≈ 1.827361993
finite difference ≈ 1.827361972
relative error ≈ 7.32e-9
```

说明在可求解的标称点上：

- IDAKLU sensitivity 有效；
- PyBaMM 到 PyTorch 的自定义反向传播基本正确；
- 物理仿真层可以在可解点提供可靠梯度。

但单点成功不等于整个随机设计空间都可以求解。

### 20.3 原容量公式造成提前欠压

原随机设计的 1C 和 3C 多次提前触发最低电压，说明理论容量或对应电流被明显高估。前向轨迹先失效，随后能量、功率、最低电压、损失和梯度一起变成 NaN。

因此，早期端到端 NaN 的主要来源不是梯度公式本身，而是容量、电流和物理仿真的不一致。

### 20.4 `chen2020_scaled` 的作用

使用：

\[
Q=5\,\mathrm{Ah}\frac{\phi_p}{0.665}
\]

后，DFN 随机样本的 1C 工况均能完成目标时间，说明该公式比原公式更接近 Chen2020 的容量尺度。

但它仍是过渡性工程公式，不能替代包含面积、厚度、活性材料和化学计量窗口的统一容量模型。

### 20.5 DFN 3C 结果

DFN 与新容量公式组合后，三个随机样本中只有一个完成 1C 和 3C，其他样本出现 IDA 求解错误。成功样本的梯度相对误差约为 \(10^{-4}\)–\(10^{-3}\) 量级。

说明：

- 成功的 DFN 样本可以传递端到端梯度；
- 当前主要瓶颈是随机结构在 3C 下的可行性和数值稳定性；
- 不能将 DFN 直接作为当前大规模训练的默认后端。

### 20.6 一秒电流平滑结果

一秒电流平滑没有提高 3C 成功率，却明显增加运行时间。说明零时刻电流突变不是当前 3C 失败的主要原因。

在没有新证据前，大规模实验可优先使用：

```text
current_ramp_time_s = 0
```

### 20.7 当前能够和不能够得出的结论

已经证明：

- Toy 梯度链正确；
- 标称 PyBaMM 物理梯度正确；
- 容量公式会直接影响仿真有效性；
- 新容量缩放改善了 1C；
- 部分 DFN 设计可以完成 3C 并传递梯度；
- 当前记录系统能够定位 NaN 和失败阶段。

尚未证明：

- 性能代理模型能够泛化到未见结构；
- 逆向设计能够根据目标稳定生成结构；
- 梯度方法优于随机搜索或其他优化基线；
- SPMe 最优结构可以通过 DFN；
- 最终设计满足完整制造约束；
- 仿真预测得到真实电芯实验验证。

当前项目仍处于物理层、梯度链、容量和数据生成前置验证阶段。

## 21. 当前代码需要优先改正的问题

### P0：失败轨迹会污染损失

当前 PyBaMM 后端在异常时返回 NaN 轨迹、零 Jacobian 和失败状态。模型却先使用 NaN 轨迹计算能量、功率、最低电压和目标函数，最后才添加失败惩罚。

由于：

\[
\mathrm{NaN}+\mathrm{penalty}=\mathrm{NaN}
\]

一个失败样本可能污染整个 batch。

正确流程应为：

```text
先检查 status、轨迹有限性和结束时间
        ↓
有效样本进入 discharge_metrics
        ↓
无效样本不计算物理性能指标
        ↓
无效样本使用有限的可行性损失或单独分类损失
```

不能简单使用 `nan_to_num` 或将缺失尾部填成最后一个电压，因为这会制造虚假的能量和梯度。

### P1：成功状态判断不严格

后端成功状态应同时要求：

```python
success = (
    solver_no_exception
    and completed_requested_horizon
    and trajectory_all_finite
    and (not need_gradient or jacobian_all_finite)
)
```

提前终止或轨迹出现 NaN 时不能继续标记为成功。

### P2：固定材料目标与扩散率设计变量冲突

纯结构模式必须将两个扩散率倍率固定为 1.0，并重新定义设计变量维度。材料联合优化只能作为独立扩展实验。

### P3：结构变量不完整

当前设计空间需要增加正负极厚度，并将厚度同时传入：

- PyBaMM；
- 容量公式；
- 质量模型；
- N/P 平衡；
- 电流计算。

### P4：容量、质量、几何和电流没有形成统一来源

应建立单一 `CellDesign` 作为所有模块的真值来源，禁止不同模块分别使用不同的面积、厚度或容量定义。

### P5：初始锂状态未随结构重新对齐

需要根据新结构和 N/P 明确计算初始 SOC、化学计量比和可循环锂库存。

### P6：默认模型职责与新路线不一致

推荐默认值：

```text
大规模数据生成：SPMe
代理训练和搜索：SPMe 数据
最终标签和复核：DFN
current_ramp_time_s：0
capacity_formula：chen2020_scaled（过渡阶段）
```

### P7：训练模式和验证模式的截止电压需分离

训练模式可以使用固定时间域和平滑电压约束；数据标签和最终验证必须使用真实工程截止电压，并且只积分有效放电区间。

## 22. 推荐实施顺序

### 阶段 A：修复数据和损失有效性

任务：

1. 严格定义后端成功状态；
2. 阻止 NaN 进入性能指标和损失；
3. 为失败样本增加统一失败类型；
4. 增加提前终止、NaN 轨迹和求解异常测试；
5. 保证任何 batch 的总损失有限。

通过标准：

```text
失败样本不会导致 batch loss 为 NaN
成功状态与结束时间和有限性一致
所有失败样本都有明确记录
```

### 阶段 B：建立纯结构设计模式

任务：

1. 固定扩散率倍率为 1.0；
2. 加入正负极厚度；
3. 建立统一容量和质量公式；
4. 对齐 N/P 和负极活性材料比例；
5. 对齐初始 SOC 和锂库存；
6. 将相同结构准确传入 SPMe 和 DFN。

通过标准：

```text
Chen2020 标称结构能够复现合理基线
结构变化能够正确改变容量、质量和电流
SPMe 与 DFN 使用完全相同的结构定义
```

### 阶段 C：100 个 SPMe 样本调试

检查：

- 输入结构是否合法；
- 容量、质量和电流是否合理；
- 1C/3C 状态是否准确；
- 曲线和指标是否有限；
- 失败原因是否保存；
- 数据能否被训练脚本完整读取。

通过标准：

```text
所有样本均有完整记录
成功样本无 NaN/Inf
失败样本不包含伪造性能标签
实验能够通过 run_id 完整复现
```

### 阶段 D：第一批 SPMe 数据和代理训练

1. 生成 2,000–5,000 个 SPMe 设计；
2. 按 design_id 划分数据；
3. 训练 SPMe 可行性分类器；
4. 训练 SPMe 性能代理模型；
5. 评估独立测试集和边界测试集。

### 阶段 E：逆向搜索和 SPMe 回代

1. 设置能量、功率、电压和质量目标；
2. 使用多起点潜变量优化；
3. 保存 Pareto 候选；
4. 与随机、Sobol、贝叶斯优化等方法比较；
5. 将候选重新运行真实 SPMe；
6. 对误差大的区域补充数据。

### 阶段 F：DFN 验证

1. 选择随机、边界和高性能设计；
2. 执行 0.5C–3C 倍率扫描；
3. 记录内部状态和失败机制；
4. 训练 DFN 可行性和 SPMe→DFN 修正模型；
5. 最终复核前 10–50 个候选。

3. 性能代理在独立测试设计上具有可靠精度；
4. 可行性模型能够识别欠压和失败区域；
5. 梯度逆向设计优于随机搜索等基线；
6. 代理候选经真实 SPMe 回代仍然成立；
7. 最优候选经 DFN 高精度复核；
8. 报告 SPMe 与 DFN 的偏差和失败边界；
9. 对模型预测和真实实验结论进行严格区分。

如果条件允许，后续还应加入少量真实电芯或公开实验数据，用于验证电压、容量和倍率趋势。

## 26. 最终总结

本项目推荐采用以下职责划分：

```text
Chen2020：提供固定材料参数和标称基准
可行解码器：产生满足制造与容量约束的电芯结构
SPMe：生成大规模结构—性能数据并支持快速搜索
性能代理：学习结构到能量、功率、电压和容量的映射
可行性模型：预测设计在目标倍率下是否可行
梯度优化器：根据目标性能反向寻找候选结构
DFN：提供高精度标签、分析失败机制并最终复核
```

当前最重要的下一步不是直接生成数千个 DFN 样本，而是依次完成：

1. 修复失败样本导致 NaN 损失的问题；
2. 严格定义后端成功状态；
3. 建立固定扩散率的纯结构模式；
4. 加入正负极厚度变量；
5. 统一容量、质量、几何和 C-rate 电流；
6. 对齐初始 SOC 和锂库存；
7. 使用 100 个 SPMe 样本完成数据链路验收；
8. 再扩大到 2,000–5,000 个 SPMe 样本训练第一版代理模型；
9. 使用 DFN 对少量关键候选进行倍率扫描和最终复核。

一句话概括：

> 使用 Chen2020 固定材料体系，随机生成可制造的电芯结构，由 SPMe 大规模计算性能并训练代理模型，通过梯度优化寻找满足目标的结构，最后使用 DFN 对候选设计进行高精度物理验证。
