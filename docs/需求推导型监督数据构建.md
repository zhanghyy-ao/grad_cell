# 需求推导型自然语言监督数据构建

_将DFN事实复述数据改造为“推导用户需求 → 监督设计参数”的训练数据_

---

## 📋 设计目标

旧数据让DeepSeek逐项复述参考容量、1C/5C/6C容量、能量、电压和放电时间。Qwen embedding因此包含大量高精度事实，MLP可能依赖数字记忆，而不是学习“用户需求—设计取舍”的关系。

新流程不把精确仿真小数写入自然语言。脚本先在同一参数集和generation mode内部计算设计性能的相对百分位，再形成能量需求、高倍率需求、电压稳定性和设计取舍画像。DeepSeek只负责把画像改写成自然的用户请求，原始七参数设计仍作为监督标签。

```text
DFN教师设计与性能
→ 同体系相对百分位
→ 抽象需求画像
→ DeepSeek用户需求
→ 冻结Qwen embedding
→ MLP七参数监督学习
```

生成文本包含稳定的结构化标签：

```text
<goal>高倍率输出优先</goal>
<energy_level>中等</energy_level>
<rate_level>高</rate_level>
<voltage_level>中高</voltage_level>
<strictness>高</strictness>
```

标签之后是DeepSeek生成的自然用户请求。文本禁止出现精确DFN小数、PyBaMM参数集名称、孔隙率、活性材料体积分数、扩散率和教师倍率，也禁止推导当前仿真无法支持的寿命、安全、成本、低温、尺寸或质量结论。

## 🚀 构建命令

先用一个物理设计做冒烟测试。一次调用会生成该设计对应的全部语言变体，比逐行调用节省API费用。

```bash
python scripts/build_inferred_requirement_dataset.py \
  --input data/multiset_dfn_language/deepseek_2158_strict_physics.jsonl \
  --output data/multiset_dfn_language/deepseek_2158_inferred_requirements_s7.jsonl \
  --manifest data/multiset_dfn_language/deepseek_2158_inferred_requirements_s7_manifest.json \
  --with-deepseek \
  --require-deepseek-success \
  --max-new-families 1
```

检查样本后继续运行全部数据；脚本会复用已成功family，不重复消费API。

```bash
python scripts/build_inferred_requirement_dataset.py \
  --input data/multiset_dfn_language/deepseek_2158_strict_physics.jsonl \
  --output data/multiset_dfn_language/deepseek_2158_inferred_requirements_s7.jsonl \
  --manifest data/multiset_dfn_language/deepseek_2158_inferred_requirements_s7_manifest.json \
  --with-deepseek \
  --require-deepseek-success
```

不调用API时可先生成确定性需求模板，检查画像和数据schema：

```bash
python scripts/build_inferred_requirement_dataset.py \
  --input data/multiset_dfn_language/deepseek_2158_strict_physics.jsonl \
  --output data/multiset_dfn_language/inferred_requirements_template_s7.jsonl \
  --manifest data/multiset_dfn_language/inferred_requirements_template_s7_manifest.json
```

## 🧪 阶段一监督训练

新数据保留`battery_description`、`teacher_design`、`verified_performance`、`split`和`physical_design_id`，因此可以直接复用现有embedding和阶段一训练脚本，但必须生成新的embedding缓存。

```bash
python scripts/extract_paper_explore_embeddings.py \
  --data data/multiset_dfn_language/deepseek_2158_inferred_requirements_s7.jsonl \
  --text-field battery_description \
  --model-name "$PWD/models/Qwen3-8B" \
  --output data/multiset_dfn_language/deepseek_2158_inferred_requirements_qwen.npz \
  --pooling mean \
  --max-length 1024 \
  --batch-size 8 \
  --dtype bfloat16 \
  --local-files-only

python scripts/train_battery_description_stage1_supervised.py \
  --data data/multiset_dfn_language/deepseek_2158_inferred_requirements_s7.jsonl \
  --embeddings data/multiset_dfn_language/deepseek_2158_inferred_requirements_qwen.npz \
  --output-dir results/inferred_requirements_stage1/seed_7 \
  --hidden-dim 512 \
  --num-blocks 2 \
  --batch-size 64 \
  --epochs 50 \
  --seed 7 \
  --device cuda
```

## ⚠️ 解释边界

需求推导会主动减少精确数值信息，因此逆映射会比事实复述更具一对多性。manifest会报告不同`profile_id`数量和最大画像组大小。如果画像种类过少，单输出MLP仍可能学习同组设计的平均值。实验必须比较预测参数方差、贴边率、原始结构可行率，以及同画像内教师设计分散程度；不能只看训练loss。

最合理的对照实验是保持相同物理设计、split、Qwen和MLP，只替换语言字段：旧组使用精确事实描述，新组使用需求推导描述。若新组测试参数误差略升，但输出多样性、需求一致性和域外应用表现改善，才能说明修改有效。
