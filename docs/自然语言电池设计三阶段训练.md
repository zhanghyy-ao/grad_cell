# 自然语言电池设计三阶段训练

## 总体链路

```text
自然语言描述
  -> 冻结的本地 Qwen3-8B embedding
  -> 阶段一：设计参数监督训练 MLP
  -> 阶段二：SPMe 1C/5C/6C 在线物理梯度训练
  -> 阶段三：少量 DFN 灵敏度校正
  -> 未参与训练的 test split 上严格 DFN 抽样验收
```

Qwen 在当前实验中只生成固定语言 embedding，不参与三个阶段的反向传播。三个阶段连续更新同一个七参数 MLP。七个参数依次为三种孔隙率、正负极活性材料体积分数和正负极扩散率倍率。

## 阶段一：设计参数监督

输入是 Qwen embedding，监督标签是数据集中 DFN 已验证设计的七个参数倍率。损失为标准化 log 参数上的 Smooth-L1。该阶段不调用 PyBaMM，目的是让 MLP 先进入可信设计区域，避免阶段二从随机输出开始频繁触发求解失败。

产物：

```text
stage1_design_supervision/best_model.pt
stage1_design_supervision/history.json
stage1_design_supervision/metrics.json
```

## 阶段二：SPMe 在线物理梯度

从阶段一权重继续训练。MLP 输出解码为实际参数后，分别进入 PyBaMM SPMe 的 1C、5C、6C 求解。电压轨迹及其 forward sensitivities 被转换为容量、能量和倍率保持率，性能误差通过 SPMe Jacobian 回传到 MLP。

总损失为：

```text
design_weight * 设计监督损失
+ performance_weight * SPMe性能损失
+ feasibility_weight * 结构可行性损失
+ support_weight * 非必要多参数扰动损失
```

该阶段使用 SPMe 是为了让在线物理梯度训练在可接受时间内完成。训练目标仍来自原始 DFN 数据，因此学到的是“接近 DFN 标签、同时受 SPMe 物理梯度约束”的设计，不应把 SPMe 输出直接当作最终 DFN 结论。

## 阶段三：DFN 抽样校正与验收

阶段三分成两个严格隔离的步骤：

1. 从 train split 固定随机抽样少量记录，以低学习率执行一轮 DFN sensitivity 校正；validation 抽样只用于模型选择。
2. 从未参与训练和模型选择的 test split 重新固定随机抽样，以严格容差运行 DFN，不计算 sensitivity、不反向传播，只作最终验收。

这样不会将 test split 用于更新权重。DFN 校正默认样本数很小，因为此前服务器实测单个三倍率 DFN sensitivity 样本约需 1176 秒。可以按服务器预算逐步提高抽样数。

最终验收同时检查：

- DFN 求解成功率；
- 每项性能的 MAPE、中位 APE 和 P90 APE；
- 八项性能同时落在相对误差阈值内的样本比例；
- 验收是否通过。

## A100 一键命令

在仓库根目录运行：

```bash
CUDA_DEVICE=2 \
QWEN_MODEL_NAME="$PWD/models/Qwen3-8B" \
THREE_STAGE_SEEDS="7" \
STAGE1_EPOCHS=50 \
STAGE1_BATCH_SIZE=64 \
STAGE2_EPOCHS=10 \
STAGE2_BATCH_SIZE=2 \
STAGE3_CORRECTION_TRAIN_RECORDS=4 \
STAGE3_CORRECTION_VALIDATION_RECORDS=2 \
STAGE3_CORRECTION_TEST_RECORDS=2 \
STAGE3_AUDIT_RECORDS=16 \
bash scripts/run_deepseek_2158_three_stage_server.sh
```

本地模型目录必须含 `config.json`，脚本会强制启用 Hugging Face 离线模式。A100 主要加速 Qwen embedding 与 MLP；PyBaMM IDAKLU 仍主要运行在 CPU，因此扩大 DFN 抽样量会近似线性增加总时长。

## 分阶段恢复

三个阶段分别写入独立目录。若阶段三耗时过长，不需要重跑前两阶段；可以直接调低或调高抽样数后，使用阶段二 checkpoint 单独执行 `train_battery_description_direct_dfn.py --physics-model DFN --initial-checkpoint ...`。

阶段二也可以单独运行：

```bash
python -X faulthandler scripts/train_battery_description_direct_dfn.py \
  --data data/multiset_dfn_language/deepseek_2158_strict_physics.jsonl \
  --embeddings data/multiset_dfn_language/deepseek_2158_physics_qwen_embeddings.npz \
  --initial-checkpoint results/deepseek_2158_three_stage/seed_7/stage1_design_supervision/best_model.pt \
  --output-dir results/deepseek_2158_three_stage/seed_7/stage2_spme_online \
  --physics-model SPMe \
  --epochs 10 --batch-size 2 --device cuda
```

严格验收报告位于：

```text
results/deepseek_2158_three_stage/seed_7/stage3_dfn_acceptance/dfn_acceptance_report.json
```
