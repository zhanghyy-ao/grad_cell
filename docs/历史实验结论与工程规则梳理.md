# GradCell 历史实验结论与工程规则梳理

> 更新日期：2026-09-09。
> 目的：为“自然语言电芯需求 → Qwen embedding → MLP → 设计参数/可行性”的下一阶段工作建立可信底稿。本文只整理当前工作区已有证据，不把计划、模型预测或工程常识冒充真实电芯实验结论。

## 1. 结论摘要

当前项目已经形成一条可运行的固定材料结构优化链：五维 latent 经硬可行解码器得到 Chen2020 电芯结构，SPMe 计算 1C/5C/6C 性能，可微损失反向训练偏好条件化初始化器。K=0 单种子正式结果在当前设计域内实现了 100% SPMe 成功率、100% 高倍率约束满足率和 100% 优于标称设计，说明“任务条件 → 连续设计”的映射在同一 SPMe 域内可学习。

但现有证据不能支持以下说法：已经设计出真实可制造的 70 Ah LFP/石墨软包电芯；已经验证 3000 次循环、低温、安全或成本性能；已经证明跨模型或跨真实电芯泛化；Qwen 三阶段训练已经完成。现有 Chen2020 模型、五维结构变量和 stack-level 质量 proxy 与目标软包电芯设计之间仍有明显范围差距。

后续生成 500 条自然语言数据时，应保留结构化真值底稿，使用确定性规则或经过验证的物理模型产生标签。DeepSeek 可以负责需求组合、语言改写和候选解释，但不能单独充当工程标签真值来源。

## 2. 证据分级

| 等级 | 定义 | 本项目中的用法 |
|---|---|---|
| A：实测证据 | 真实电芯或材料实验，条件、样本和测量可追溯 | 当前工作区尚无能覆盖完整五维结构—性能关系的实测数据 |
| B：高可信仿真结果 | 有原始产物、严格评价和明确模型边界 | K=0 SPMe 正式结果、固定材料 SPMe 监督数据 |
| C：软件/数值证据 | 单元测试、梯度核对、smoke test | 解码器约束、autograd 梯度、流水线可运行性 |
| D：代码规则 | 当前实现中确定性执行的公式、范围和检查 | 孔隙率范围、N/P、容量平衡、质量 proxy |
| E：方案或假设 | 文档中的计划、验收目标或待实现架构 | Qwen S1/S2/S3 方案、70 Ah LFP 规则、循环和低温目标 |

写入训练集时，建议为每条标签保存 `evidence_level` 和 `provenance`。A/B/D 可以作为主要监督来源；C 只能证明软件行为；E 只能生成候选或待审核样本。

## 3. 已有实验结论

### 3.1 可微物理梯度链成立（C）

`results/gradient_physics.json` 中，自动微分方向导数为 `-0.0762745208147509`，有限差分为 `-0.07627452001557344`，相对方向误差为 `7.43e-10`。这说明该测试点上的自定义物理反传与有限差分高度一致。

适用边界：这证明的是指定模型、参数点和损失下的数值梯度实现，不证明所有设计点都稳定，也不证明物理模型等同于真实电芯。

### 3.2 固定材料 SPMe 映射可由普通 MLP 学习（B）

`results/fixed_material_spme_100_seed17/metrics.json` 记录了 100 条样本、70/15/15 划分和 0% 数据生成失败率。测试集主要指标如下：

| 目标 | MAE | R² |
|---|---:|---:|
| 参考容量 | 0.0310 Ah | 0.9825 |
| 1C 放电容量 | 0.0279 Ah | 0.9820 |
| 3C 放电容量 | 0.0719 Ah | 0.3549 |
| 1C 比能量 | 1.378 Wh/kg | 0.9870 |
| 3C 比功率 | 8.552 W/kg | 0.8930 |
| 1C 平均电压 | 0.00128 V | 0.9474 |
| 3C 平均电压 | 0.0306 V | 0.1994 |

结论：在当前固定材料、同分布、小型 SPMe 数据域内，容量和 1C 比能量较容易拟合；3C 容量、3C 平均电压和放电时间明显更难。后续 MLP 不应只报告一个平均损失，必须逐目标报告指标。

限制：测试集只有 15 条，结论不能外推到 LFP、70 Ah、软包结构或寿命预测。

### 3.3 K=0 已学习到偏好到设计的连续映射（B）

正式 K=0 结果来自单个模型种子 7、参考数据种子 101。5000 个随机可行设计用于构建有限 SPMe 参考集；训练本身是在线物理优化，不是对这 5000 条做普通监督拟合。

在 21 个标准偏好点上：

| 指标 | 结果 |
|---|---:|
| SPMe 成功率 | 1.0000 |
| 5C/6C 约束满足率 | 1.0000 |
| 优于标称设计比例 | 1.0000 |
| 平均 / 中位 regret | 0.006311 / 0.001241 |
| 唯一设计数 | 21/21 |
| 1C 比能量范围 | 113.8299–159.7662 Wh/kg |
| 5C 能量保持率范围 | 0.515186–0.522984 |
| 6C 能量保持率范围 | 0.442010–0.461338 |

在 20 个离网格中点上，成功率、约束满足率和优于标称设计比例也均为 1.0；平均/中位/最大 regret 为 0.005442/0.002290/0.032285，能量和 6C 保持率均无单调性违反。

严格表述：K=0 在当前 Chen2020、五维设计域和 SPMe 同分布偏好插值任务上学到了有意义的条件映射。它尚未证明跨随机种子、严格 held-out 偏好区间、DFN、真实电芯或其他化学体系的泛化。

### 3.4 线性约束罚项优于此前平方罚项（B）

平方罚项版本的约束满足率为 20/21，平均 regret 为 0.007058；改为线性 ReLU 罚项后分别改善为 21/21 和 0.006311，中位 regret 从 0.002848 降至 0.001241。最高比能量下降不足 1 Wh/kg，但消除了已知的 6C 约束违反。

规则：对必须满足的单边阈值，当前实验优先使用线性违反量；硬结构约束则直接写入解码器，不依赖罚项学习。

### 3.5 高倍率响应具有强非均匀性和膝点（B）

5000 个 SPMe 样本中，5C 保持率中位数为 0.14935、P75 为 0.51276；6C 中位数为 0.08660、P90 为 0.45301。早期设置的 `R5 ≥ 0.55` 超过样本观测最大值 0.52306，导致可行集为空，后来调整为 `R5 ≥ 0.50`、`R6 ≥ 0.44`。

规则：性能阈值必须先依据有效数据分布和联合可行数量标定；不能凭经验直接指定后再强迫模型拟合。数据生成应在膝点、边界和高 regret 区域加密，而不是均匀随机。

### 3.6 当前五维空间的有效变化接近二维（B）

K=0 标准网格上五个 latent 的标准差约为 `[1.32e-4, 1.52e-4, 1.04e-4, 1.28, 1.56]`。前三维孔隙率相关 latent 基本贴近上界，主要取舍由正极活性材料比例相关变量和 N/P 比承担。

可能解释包括：当前目标偏好边界设计、结构范围或质量模型把最优解推到边界，也可能是物理模型的真实趋势。现有数据无法区分。后续扩展数据前应先做边界敏感性和更宽设计域验证。

### 3.7 传统单变量优化结果不能作为工程增益证据（C）

传统优化示例中，正极孔隙率从 0.335 调至约 0.3977 时，记录的能量增益达到 1372%。但基准点仅放电约 59 s，优化点约 1085 s，且容量、电流随设计同时变化。该结果主要暴露了容量口径和单变量目标耦合问题，不能解释为真实电芯能量提升 1372%。

规则：比较设计时必须统一容量定义、C-rate 电流、截止规则、质量口径和有效放电判据；明显超常的提升首先按口径问题审计。

### 3.8 电解液实验暴露了数据拆分和小样本物理正则风险（B/C）

CALiSol-23 审计发现缺失电导率、负浓度、盐名称污染、同义名、零值和类别覆盖问题。普通 one-hot MLP 只能对训练中出现的类别插值，不能据此声称新盐或新溶剂外推。DOI 分组若不约束化学类别覆盖，会使验证/测试集出现训练集未见类别。

smoke 结果中，analytic 物理版本测试 `R²=0.541`，少量 DFN 物理样本版本为 `R²=-0.082`；另一个仅含 2 个物理样本的矩阵 smoke test 也比无物理项更差。由于这些是 smoke test，不能得出“物理约束无效”，但可以得出：极少量或失配的物理样本不会自动改善模型。

规则：数据划分按配方/实验曲线分组，并审计类别覆盖；物理正则必须通过独立消融验证，不能只因引入 DFN 就默认更可信。

## 4. 当前确定性工程规则

以下规则来自当前代码，只适用于 Chen2020 固定材料的第一版设计域。

### 4.1 五维设计变量（D）

| 变量 | 当前范围/来源 |
|---|---|
| 正极孔隙率 `eps_p` | 0.20–0.42 |
| 负极孔隙率 `eps_n` | 0.20–0.42 |
| 隔膜孔隙率 `eps_s` | 0.35–0.60 |
| 正极活性材料体积分数 `phi_p` | 最小 0.20，上界由孔隙率、非活性相和负极容量共同决定 |
| N/P | 1.02–1.25 |
| 负极活性材料体积分数 `phi_n` | 由 `phi_p` 和 N/P 容量平衡推导，不独立预测 |

正负极最小非活性固相比例均为 0.03。当前正负极固相扩散系数乘子固定为 1.0，因此现有模型优化的是结构，不是材料化学性质。

### 4.2 容量平衡（D）

当前实现使用

\[
\phi_n=\mathrm{N/P}\cdot
\frac{L_p c_{\max,p}\Delta\theta_p}
{L_n c_{\max,n}\Delta\theta_n}\phi_p
\]

确保负极/正极容量比满足目标 N/P。当前常数包含正极厚度 `75.6 μm`、负极厚度 `85.2 μm`、两极化学计量利用窗口均为 0.75、有效面积 `0.1027 m²`。

规则：若 N/P 是模型输出，`phi_n` 应由容量平衡推导；不要同时独立预测 N/P、`phi_p` 和 `phi_n` 而不做闭合约束。

### 4.3 标称容量和倍率电流（D）

代码支持电极理论容量和 `chen2020_scaled` 两种口径。K=0 正式实验使用后者，并乘以校准系数 1.2589438522。倍率电流按

\[
I_C=Q_{nominal}\times C
\]

计算。

规则：训练数据中必须保存 `capacity_formula`、校准系数和电流计算口径；不同容量公式产生的结果不得直接混合。

### 4.4 质量模型（D）

当前质量 proxy 包括正负极活性/非活性固相、孔隙电解液、隔膜、正负集流体和 10 g 固定硬件质量。它仍未覆盖涂布损失、额外注液、封边、极耳焊接、绝缘件细节、制造余量和良率。

规则：当前 `stack_mass_kg` 只能作为同一模型内部的相对比较指标，不能直接作为 70 Ah 软包成品质量标签。

### 4.5 仿真成功与失败处理（D）

一个有效样本至少需要：求解成功；轨迹和指标有限；达到规定时间范围或合法截止事件；通过制造和容量约束。求解失败必须保留失败标签和原因，不能用零轨迹或手工修改参数伪装为成功样本。

训练时的软截止用于保持可微；正式评价必须使用 hard-cutoff 仿真。SPMe 用于训练与筛选，DFN 只能称为更高保真复核，二者均不等于真实实验。

## 5. 已有语言模型工作的真实状态

| 模块 | 当前证据 | 可下结论 | 不可下结论 |
|---|---|---|---|
| S1 JSON 语义训练 | 有代码、训练说明和验收条件；本地未发现正式 `gradcell_lm` 训练产物 | 已定义结构化任务、JSON schema、latent/level 辅助头 | 不能声称 JSON 解析率已达到 100% |
| S2 K=0 物理训练 | 当前代码说明为 legacy `projector + continuous_head` 路径 | 已定义连续 head 到可微物理的路径 | 不能声称 Qwen level-token 已接受物理梯度训练 |
| S3 K=3 refiner | 有代码与 smoke 产物 | 已定义 K=0 到 K=3 的有限步细化和 best-step 选择 | 不能声称正式 K=3 优于 K=0 |
| 非结构化输入 + embedding + MLP | 用户提出的新方向 | 可以基于当前任务 codec 和设计标签重构 | 尚无数据、训练结果或基线比较 |

因此，下一版应把“旧结构化 JSON 生成实验”和“新自然语言 embedding 回归实验”分开命名、分开数据目录、分开报告。

## 6. 面向 70 Ah LFP/石墨软包需求的缺口

示例需求包含 70 Ah、3.2 V、软包叠片、20×150×220 mm、质量不超过 1500 g、0.5C 循环 3000 次后容量保持率不少于 80%，并兼顾安全、成本和低温。当前项目尚缺：

1. LFP/石墨专用参数集及其真实标定；当前主要证据基于 Chen2020 固定材料体系。
2. 从单层/参考面积扩展到 70 Ah 多层叠片的几何、层数、双面涂布、封边和极耳模型。
3. 成品级 BOM 质量模型与体积闭合检查。
4. 循环退化模型及 3000 次循环实测校准。
5. 低温充放电条件、析锂风险和温升模型。
6. 安全指标的可计算标签，例如热稳定裕量、短路/过充设计规则或安全等级。
7. 成本数据库、价格日期、良率和制造成本口径。

在补齐这些模块前，模型最多输出“概念设计候选/可行性初筛”，不能输出“已经满足寿命与安全目标的工程定型方案”。

## 7. 下一阶段数据规则

### 7.1 保留双层数据表示

每条样本必须同时保存：

- `requirement_text`：给 Qwen 的自然语言输入；
- `requirements_canonical`：标准化需求真值；
- `design_target`：MLP 监督标签；
- `verification`：容量、尺寸、质量和物理检查结果；
- `provenance`：标签来源、模型版本、随机种子和证据等级；
- `quality_flags`：缺失、冲突、越界、求解失败和人工审核状态。

非结构化只发生在模型输入侧，底稿不能丢失结构。

### 7.2 DeepSeek 的允许角色

DeepSeek 可以：生成需求组合的语言变体；打乱参数顺序；转换单位；生成模糊、缺失或冲突表达；为已验证设计生成解释。

DeepSeek 不应单独决定：活性材料面密度、层数、N/P、注液量、循环寿命、安全等级或最终可行性。此类字段必须来自规则、物理计算、受控数据库或人工审核。

### 7.3 500 条首批数据的建议构成

| 类型 | 数量 | 用途 |
|---|---:|---|
| 常规可行需求 | 300 | 主体监督训练 |
| 边界可行需求 | 100 | 学习尺寸、质量、容量和性能边界 |
| 明显冲突/不可行需求 | 50 | 训练可行性分类和拒答原因 |
| 信息缺失、歧义或单位变化 | 50 | 训练鲁棒性和缺失字段识别 |

同一结构化需求的多种语言改写必须按 `requirement_family_id` 成组划分，不能让同源改写同时进入训练集和测试集。

### 7.4 MLP 标签的第一版范围

第一版只建议预测当前有规则或可验证标签的字段：五维 latent 或对应五个结构量、可行性分类、容量/质量 proxy 和 SPMe 性能。循环寿命、安全、成本和低温指标先作为需求特征或“暂无可信标签”，不要用大模型臆测数值进行监督。

## 8. 必须完成的验证与决策

在生成 500 条正式数据前：

1. 决定新任务继续使用 Chen2020 作为方法验证，还是先建立 LFP/石墨参数和 70 Ah 几何模型。
2. 定义 MLP 固定输出：预测五维 latent、实际结构参数、性能，还是多头联合输出。
3. 编写容量、层数、厚度、外形、质量和 N/P 的确定性检查器。
4. 建立 20–30 条人工审核的黄金样本。
5. 先生成 50 条试验数据，检查标签闭合率、重复率和不可行样本质量，再扩至 500 条。
6. 建立结构化字段 MLP 基线，与 Qwen embedding + MLP 做公平对照。
7. 至少使用 3 个随机种子，并按需求族分组划分数据。

K=0 旧实验仍需补做：3–5 个训练种子、严格 held-out 偏好区间、正式阈值下的联合可行样本数、DFN 外部复核、设计域边界敏感性和真实实验锚点。

## 10. 当前可采用的总原则

1. 先保证物理和几何闭合，再追求语言多样性。
2. 把硬约束写进解码器或检查器，不让网络从错误标签中自行学习。
3. 区分实测、仿真、代码规则和大模型生成，并全程保存来源。
4. 非结构化输入不等于非结构化标签；训练真值必须可验证、可计算、可追溯。
5. 同分布 SPMe 成功不能外推为真实 LFP 软包设计成功。
6. 500 条数据用于验证路线，不足以支撑宽设计域和多目标工程承诺。
